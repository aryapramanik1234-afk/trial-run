# Image sources & usage notes

All photos are stored locally in `images/`; the website does not request image files from a third-party host at runtime. The three original images below were generated specifically for this fictional demo:

- `hero-monsoon-mug.jpg`
- `story-interior.jpg`
- `gallery-table.jpg`

The remaining photos were sourced from Pexels search results and saved locally in a compressed 500-pixel format for the small menu/gallery placements. Pexels describes its license at <https://www.pexels.com/license/>. The source pages surfaced with the image results are listed here:

The source pages above are search pages where a direct creator page was not available in the image result, so they are not a substitute for checking the original creator and current license. Before deploying for a real client, confirm each stock photo's current license and attribution requirements, or replace it with photography supplied/approved by that client. Keep the corresponding `alt` text and image fallback paths accurate when swapping files.
